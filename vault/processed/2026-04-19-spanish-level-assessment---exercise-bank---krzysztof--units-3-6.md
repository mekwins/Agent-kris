## EXERCISE BANK FOR RECALL PRACTICE

### TOPIC 1: Reflexive vs Non-Reflexive Verbs

**Pattern**: reflexive = action on self | non-reflexive = action on someone/something else

**Example exercises:**
Choose the correct form (lavarse/lavar):
1. Ella ________ el coche todos los sábados. → *lava*
2. Él ________ antes de desayunar. → *se lava*
3. La madre ________ a su bebé. → *baña*
4. Yo ________ muy tarde los domingos. → *me levanto*
5. ¿A qué hora ________ tú? → *te acuestas*

**Conjugation drill** — acostarse (o→ue):
me acuesto / te acuestas / se acuesta / nos acostamos / os acostáis / se acuestan

---

### TOPIC 2: Preposiciones de Tiempo

**Pattern**: desde…hasta (duration) | a (point in time) | por (general part of day) | de (specific AM/PM) | en (month/transport)

**Example exercises — fill in the blank:**
1. Los bancos abren ________ las 8 ________ las 3. → *desde / hasta*
2. Voy al trabajo ________ autobús. → *en*
3. Me levanto ________ las 7 ________ la mañana. → *a / de*
4. Estudio ________ la noche. → *por*
5. El concierto empieza ________ las 9. → *a*
6. Trabajo ________ lunes ________ viernes. → *desde el / hasta el*

---

### TOPIC 3: HAY / ESTAR / SER / TENER

**Rules**:
- HAY = existence/quantity (impersonal, never changes)
- ESTÁ/ESTÁN = location of a known specific thing
- ES/SON = description, identity, profession, inherent quality
- TIENE/TIENEN = possession

**Example exercises — choose the correct verb:**
1. ________ una farmacia cerca de aquí. → *Hay*
2. ¿Dónde ________ los baños? → *están*
3. Mi piso ________ muy pequeño pero cómodo. → *es*
4. ¿________ tu madre microondas en la cocina? → *Tiene*
5. La estantería ________ a la derecha de la tele. → *está*
6. ________ dos restaurantes en mi calle. → *Hay*
7. Este ejercicio no ________ bien. → *está* (state/result)
8. Salamanca ________ una ciudad muy bonita. → *es*

---

### TOPIC 4: SER vs ESTAR (Advanced Distinction)

**Key rule**: SER = permanent/inherent | ESTAR = location/temporary state
**Traps**: emotions (estar), results of change (estar), location ALWAYS estar

**Example exercises — correct the error or choose:**
1. Mi casa *es* en un barrio tranquilo. → ✗ → *está*
2. Roberto *está* rubio y delgado. → ✗ → *es*
3. Fumar *está* malo para la salud. → ✗ → *es*
4. Los alumnos *son* en la clase. → ✗ → *están*
5. ¿*Es* cerca la estación de metro? → ✗ → *Está*
6. Estoy muy cansada. → ✓ (temporary state)
7. Es médico. → ✓ (profession)

---

### TOPIC 5: Definite vs Indefinite Articles

**Pattern**: el/la/los/las = known thing | un/una/unos/unas = new/unknown thing

**Example exercises:**
1. Compro ________ periódico todas las mañanas. → *el*
2. Cerca de mi casa hay ________ mercado. → *un*
3. ________ amigos de Juan son muy jóvenes. → *Los*
4. Este piso tiene ________ cuarto de baño muy grande. → *un*
5. ________ mesa y ________ sillas están en el jardín. → *La / las*
6. Jesús es ________ marido de ________ amiga de mi hermana. → *el / una*

---

### TOPIC 6: El Imperativo (tú / usted)

**Regular pattern**:
- AR verbs: tú = -a, usted = -e (habla/hable, compra/compre)
- ER/IR verbs: tú = -e, usted = -a (come/coma, abre/abra)

**Irregular tú forms** (must memorize):
poner→pon | hacer→haz | venir→ven | ir→ve | ser→sé | tener→ten | salir→sal | decir→di

**Example exercises — write the imperative:**
1. (comprar, tú) ________ productos frescos. → *Compra*
2. (abrir, usted) ________ la ventana. → *Abra*
3. (hacer, tú) ________ la tarea ahora. → *Haz*
4. (poner, tú) ________ los libros en la mochila. → *Pon*
5. (venir, tú) ________ aquí. → *Ven*
6. (limpiar, tú) ________ la cocina. → *Limpia*
7. (seguir, tú) ________ por esta calle. → *Sigue*
8. (pedir, usted) ________ la cuenta. → *Pida*

**Cooking recipe drill** — complete with imperative:
- ________ (lavar) la lechuga. → *Lava*
- ________ (cortar) las verduras en trozos pequeños. → *Corta*
- ________ (mezclar) el atún con las verduras. → *Mezcla*
- ________ (añadir) aceite y sal. → *Añade*
- ________ (servir) la ensalada. → *Sirve*

### TOPIC 7: GUSTAR + Pronouns

**Structure**: (A + noun/pronoun) + indirect object pronoun + gusta/gustan
Pronouns: me, te, le, nos, os, les

**gusta** = with singular noun or infinitive
**gustan** = with plural noun

**Example exercises — fill pronoun + gusta/gustan:**
1. A mi hermana ________ ________ cocinar. → *le / gusta*
2. A nosotros ________ ________ los libros de historia. → *nos / gustan*
3. A ti y a tus amigos ________ ________ las pizzas? → *os / gustan*
4. A mis padres ________ ________ ver la televisión. → *les / gusta*
5. A mí no ________ ________ las verduras. → *me / gustan*
6. A ustedes ________ ________ jugar al tenis? → *les / gusta*

**Agreement response drill** — respond with a mí también/tampoco/sí/no:
1. Me gusta mucho el cine. (you agree) → *A mí también.*
2. No me gusta bailar. (you DO like it) → *A mí sí.*
3. Me gustan las películas de terror. (you don't like them) → *A mí no.*
4. No me gusta cocinar. (you also don't like it) → *A mí tampoco.*

### TOPIC 9: Describing a House / Neighborhood

**Useful structures**:
- Hay + indefinite article + noun (existence)
- Está/están + location (position)
- Es/son + adjective (description)
- Tiene/tienen + noun (features)

**Free writing prompt for practice:**
*Describe tu casa ideal. ¿Dónde está? ¿Cuántas habitaciones tiene? ¿Hay jardín o terraza? ¿Cómo es el salón?*
(Target: 80–100 words, use hay/estar/ser/tener, include location prepositions)

### TOPIC 10: Food Vocabulary + Ordering in a Restaurant

**Menu categories**:
- Entradas/Primer plato: sopa de fideos, gazpacho, ensalada mixta
- Plato fuerte: salmón a la plancha, pollo asado, escalope de ternera, chuletas de cordero, pasta boloñesa
- Postre: helado, flan, fruta, arroz con leche
- Bebidas: agua mineral, vino tinto/blanco, cerveza, zumo de naranja

**Dialogue drill** — complete the restaurant conversation:
Camarero: ¿Qué van a tomar de primer plato?
Cliente A: Yo ________ de primer plato ________. → *quiero / sopa de fideos*
Camarero: ¿Y de segundo?
Cliente B: ________ quiero ________. → *De segundo / pollo asado*
Camarero: ¿Para beber?
Cliente A: ________ favor, ________. → *Por / agua mineral*
