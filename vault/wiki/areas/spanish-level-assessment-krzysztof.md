# Spanish Level Assessment — Krzysztof (Units 3–6)

A learner assessment and structured exercise bank for [[Krzysztof]], based on Units 3–6 of the Cuaderno de Tareas. Overall level: **A2 (solid) → approaching A2+**. Exercises are designed for spaced-repetition recall practice targeting his known error patterns.

## Key Points
- Assessed across 10 grammar/vocabulary topics
- Strongest areas: reflexive verbs, time prepositions, food vocabulary, regular imperatives, gustar distinction
- Weakest areas: ser/estar, irregular tú imperatives, reflexive vs non-reflexive choice, gustar plural agreement

---

## Exercise Bank

### Topic 1: Reflexive vs Non-Reflexive Verbs
**Rule**: reflexive = action on self | non-reflexive = action on someone/something else

| Sentence | Answer |
|---|---|
| Ella ________ el coche todos los sábados. | *lava* |
| Él ________ antes de desayunar. | *se lava* |
| La madre ________ a su bebé. | *baña* |
| Yo ________ muy tarde los domingos. | *me levanto* |
| ¿A qué hora ________ tú? | *te acuestas* |

**Conjugation drill — acostarse (o→ue):**
me acuesto / te acuestas / se acuesta / nos acostamos / os acostáis / se acuestan

---

### Topic 2: Preposiciones de Tiempo
**Pattern**: desde…hasta (duration) | a (point in time) | por (general part of day) | de (specific AM/PM) | en (month/transport)

| Sentence | Answer |
|---|---|
| Los bancos abren __ las 8 __ las 3. | *desde / hasta* |
| Voy al trabajo __ autobús. | *en* |
| Me levanto __ las 7 __ la mañana. | *a / de* |
| Estudio __ la noche. | *por* |
| El concierto empieza __ las 9. | *a* |
| Trabajo __ lunes __ viernes. | *desde el / hasta el* |

|---|---|

### Topic 4: SER vs ESTAR (Advanced Distinction)
**Traps**: emotions (estar), results of change (estar), location ALWAYS estar

| Sentence | Correct? | Fix |
|---|---|---|
| Mi casa *es* en un barrio tranquilo. | ✗ | *está* |
| Roberto *está* rubio y delgado. | ✗ | *es* |
| Fumar *está* malo para la salud. | ✗ | *es* |
| Los alumnos *son* en la clase. | ✗ | *están* |
| ¿*Es* cerca la estación de metro? | ✗ | *Está* |
| Estoy muy cansada. | ✓ | (temporary state) |
| Es médico. | ✓ | (profession) |

| Sentence | Answer |
|---|---|

| ________ mesa y ________ sillas están en el jardín. | *La / las* |

### Topic 6: El Imperativo (tú / usted)
**Regular**: AR → tú: -a / usted: -e | ER/IR → tú: -e / usted: -a
**Irregular tú forms**: poner→pon | hacer→haz | venir→ven | ir→ve | ser→sé | tener→ten | salir→sal | decir→di

| Sentence | Answer |
|---|---|
| (comprar, tú) ________ productos frescos. | *Compra* |
| (abrir, usted) ________ la ventana. | *Abra* |
| (hacer, tú) ________ la tarea ahora. | *Haz* |
| (poner, tú) ________ los libros en la mochila. | *Pon* |
| (venir, tú) ________ aquí. | *Ven* |
| (limpiar, tú) ________ la cocina. | *Limpia* |
| (seguir, tú) ________ por esta calle. | *Sigue* |
| (pedir, usted) ________ la cuenta. | *Pida* |

**Cooking recipe drill:**
- ________ (lavar) la lechuga. → *Lava*
- ________ (cortar) las verduras en trozos pequeños. → *Corta*
- ________ (mezclar) el atún con las verduras. → *Mezcla*
- ________ (añadir) aceite y sal. → *Añade*
- ________ (servir) la ensalada. → *Sirve*

### Topic 7: GUSTAR + Pronouns
**Structure**: *(A + noun/pronoun)* + indirect object pronoun + gusta/gustan
**gusta** = singular noun or infinitive | **gustan** = plural noun

| Sentence | Answer |
|---|---|
| A mi hermana __ __ cocinar. | *le / gusta* |
| A nosotros __ __ los libros de historia. | *nos / gustan* |
| ¿A ti y a tus amigos __ __ las pizzas? | *os / gustan* |
| A mis padres __ __ ver la televisión. | *les / gusta* |
| A mí no __ __ las verduras. | *me / gustan* |
| ¿A ustedes __ __ jugar al tenis? | *les / gusta* |

**Agreement response drill:**
1. Me gusta mucho el cine. (you agree) → *A mí también.*
2. No me gusta bailar. (you DO like it) → *A mí sí.*
3. Me gustan las películas de terror. (you don't like them) → *A mí no.*
4. No me gusta cocinar. (you also don't like it) → *A mí tampoco.*

**Key verbs**: tomar, bajar, cambiar, seguir, girar, ir

|---|---|

### Topic 9: Describing a House / Neighborhood
**Key structures**: Hay + indefinite + noun | Está/están + location | Es/son + adjective | Tiene/tienen + noun

**Free writing prompt:**
> *Describe tu casa ideal. ¿Dónde está? ¿Cuántas habitaciones tiene? ¿Hay jardín o terraza? ¿Cómo es el salón?*
> Target: 80–100 words, use hay/estar/ser/tener, include location prepositions.

---

### Topic 10: Food Vocabulary + Ordering in a Restaurant
**Menu categories:**
- Entradas/Primer plato: sopa de fideos, gazpacho, ensalada mixta
- Plato fuerte: salmón a la plancha, pollo asado, escalope de ternera, chuletas de cordero, pasta boloñesa
- Postre: helado, flan, fruta, arroz con leche
- Bebidas: agua mineral, vino tinto/blanco, cerveza, zumo de naranja

**Dialogue drill:**
- Camarero: ¿Qué van a tomar de primer plato?
- Cliente A: Yo ________ de primer plato ________. → *quiero / sopa de fideos*
- Cliente B: ________ quiero ________. → *De segundo / pollo asado*
- Cliente A: ________ favor, ________. → *Por / agua mineral*
