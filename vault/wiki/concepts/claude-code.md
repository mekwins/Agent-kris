# Claude Code

Claude Code is Anthropic's CLI-based agentic tool designed for software engineering tasks. It can read, write, and edit files, run tests, and interact with Git, making it a capable autonomous coding agent. It supports MCP (Model Context Protocol) servers to extend its capabilities with custom tools.

## Key Points
- CLI tool from Anthropic; operates as a software engineering agent in a local environment
- Capabilities: file read/write/edit, test execution, Git interaction
- Extensible via [[MCP (Model Context Protocol)]] servers for custom tooling
- Relevant to Nexteer's Claude Enterprise procurement and Vibe Coding initiative
