# MCP

MCP (Model Context Protocol) is a protocol that allows AI models to connect to external tools, data sources, and services through a standardised server interface. It is a key extensibility mechanism in agentic AI systems.

## Key Points
- Enables AI agents to call custom tools beyond their built-in capabilities
- Works via MCP servers that expose specific functions or data to the model
- Used by [[Claude Code]] to extend its software engineering toolset with project-specific integrations
- Relevant to enterprise architecture as it defines how AI agents interface with existing systems
