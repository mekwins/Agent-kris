# Coolify Infrastructure at Nexteer

Coolify is the governed PaaS sandbox deployed by Kris Mekwinski for Nexteer's Vibe Coding initiative. It provides a controlled, sanctioned environment for employee-built AI applications, preventing shadow IT while enabling monitored deployment of vibe-coded apps.

## Key Points
- **URL**: `192.168.50.60:8000` (internal)
- **Team isolation**: Vibecoders team with per-team/per-project API token scoping
- **Deployed apps**: FiveWhyAI (confirmed)
- Acts as the green-zone sandbox within the green/yellow/red risk governance framework
- Enables audit trails, access control, and monitoring for employee AI projects
- Part of the Platform & Infrastructure pillar in the [[Nexteer AI Strategy]]
