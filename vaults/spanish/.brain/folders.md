# Spanish Vault — Folder Routing

| Folder | Route content here when... |
|--------|---------------------------|
| `wiki/learning/` | Default home for everything: lessons, homework, vocab, grammar, assessments |
| `wiki/concepts/` | Only for genuinely reusable references you'd want regardless of a lesson |

## Conventions
- Use flat, descriptive page titles: "Vocab: Food", "Grammar: Preterite vs Imperfect", "Assessment: Units 3-6".
- Lessons/homework → `wiki/learning/`.
- Keep pages short and reviewable; prefer bullet lists.
- No `people/`, `projects/`, or `areas/` folders in this vault — it's a learning log.
