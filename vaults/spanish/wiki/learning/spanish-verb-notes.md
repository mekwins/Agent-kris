# Spanish Verb Notes – recibir, poner, decir

Key Spanish verbs looked up during a ChatGPT conversation (April 2026), along with a mini English CEFR level assessment. Useful as a quick reference for early vocabulary and irregular verb patterns.

## Key Points

### Vocabulary
| Spanish Verb | Meaning | Notes |
|---|---|---|
| **recibir** | to receive | regular -ir verb |
| **poner** | to put / to place | irregular — *yo pongo* |
| **decir** | to say / to tell | highly irregular — *yo digo*, stem *dij-* in preterite, *dir-* in future |

### poner — Common Uses
- *Poner la mesa* → "to set the table"
- *Poner la televisión* → "to turn on the TV"
- *Poner atención* → "to pay attention"
- *Ponerse la ropa* → "to put on clothes"
- *Ponerse triste* → "to become sad" (reflexive = to become)

### decir — Mini Conjugation Reference

**Present:**
| Person | Form |
|---|---|
| yo | digo |
| tú | dices |
| él/ella | dice |
| nosotros | decimos |
| vosotros | decís |
| ellos | dicen |

**Preterite:**
| Person | Form |
|---|---|
| yo | dije |
| tú | dijiste |
| él/ella | dijo |
| nosotros | dijimos |
| vosotros | dijisteis |
| ellos | dijeron |

**Future:**
| Person | Form |
|---|---|
| yo | diré |
| tú | dirás |
| él/ella | dirá |
| nosotros | diremos |
| vosotros | diréis |
| ellos | dirán |

> ⚡ *Decir* is highly irregular: stem changes across *dic-* (present), *dij-* (preterite), *dir-* (future).

## CEFR Level Reference

The **CEFR** (Common European Framework of Reference for Languages) is the international standard for language ability, ranging from A1 to C2.

| Level | Label | What you can do |
|---|---|---|
| A1 | Beginner | Basic phrases, introduce yourself |
| A2 | Elementary | Simple routine tasks, shopping, directions |
| B1 | Intermediate | Most everyday situations, describe experiences |
| B2 | Upper Intermediate | Fluent/spontaneous interaction, complex texts |
| C1 | Advanced | Fluent & flexible, academic/professional use |
| C2 | Proficient | Near-native, understand virtually everything |

### Personal English Assessment (from session)

- Adapts language complexity to the listener's background
- Uses analogies (e.g., database ≈ Excel spreadsheet) to bridge technical gaps

### Exercise Corrections (from session)
Errors caught on a conjugation worksheet:
- *quereir* → **queréis** (vosotros querer)
- *vemos* → **vamos** (nosotros ir — not ver)
- *olicen* → **dicen** (ellos decir)
- *apremdo* → **aprendo** (yo aprender)
