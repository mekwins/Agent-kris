# Agents

AI agents are systems that autonomously plan and execute multi-step tasks by calling tools, reading context, and taking actions — rather than simply responding to a single prompt. They are a central pattern in modern AI strategy.

## Key Points
- Operate with a degree of autonomy, making sequential decisions to accomplish a goal
- Rely on tool-use frameworks (such as [[MCP]]) to interact with external systems
- [[Claude Code]] is a concrete example: an agent that reads/writes files, runs tests, and uses git
- Raise governance and oversight questions relevant to [[Enterprise Architecture]]

## Related Concepts
- [[MCP]] — the protocol layer that gives agents access to external tools and data
- [[Claude Code]] — a practical, production agentic system for software engineering
