# Capability Pods

A capability pod is a small, focused team organized around a specific set of technical competencies rather than around a project or business unit. Each pod owns a domain of expertise, executes real business projects to build and validate that expertise, and produces reusable reference architectures (Blessed Patterns) for the broader organization.

## Key Points
- **Capability-first, not project-first:** projects are chosen because they exercise the pod's skills; business value is real but the deeper goal is pattern validation
- **Blessed Patterns Library:** every pod project outputs a reusable reference architecture that domain teams adopt instead of reinventing
- **Hands-on capability levels:** mastery is evaluated by doing (design, deploy, operate), not by completing training
- **Cross-functional composition:** domain experts + IT specialists + sourced depth engineers all collaborate within a pod's project
- Used within [[IT 2.0 Modern Technical Architecture]] as the core organizational model
